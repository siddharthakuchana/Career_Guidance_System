# Career Guidance System

The Career Guidance System is a web-based application designed to assist users in identifying suitable career paths based on their skills and interests. The system integrates a Machine Learning model with a PHP-based backend to generate accurate career recommendations.

The application analyzes user-provided skill levels and predicts the top career options that best match the user’s profile, helping students and professionals make informed career decisions.

---

## Key Features

- Machine Learning–based career prediction
- Displays top three recommended career options
- PHP and Python integration using JSON
- Pre-trained and optimized ML model
- Career-specific information pages
- Modular and scalable architecture

---

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Machine Learning:** Python, Scikit-learn, NumPy, Joblib  
- **Database:** MySQL  

---

## System Workflow

1. Users enter their skill levels through a web form.
2. The PHP backend sends the data to a Python script in JSON format.
3. The Machine Learning model processes the input.
4. The system predicts and returns the most suitable career options.
5. Results are displayed on the web interface.

---

## Setup and Execution

1. Clone the repository to your local system.
2. Install the required Python dependencies.
3. Configure database credentials in the backend configuration file.
4. Deploy the project on a local server environment such as XAMPP or WAMP.
5. Access the application through a web browser.

---

## Output

The system provides a list of recommended career paths based on the user’s skills and interests.
